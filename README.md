# JobPulse – Job Scraping REST API

## Project Description
JobPulse is a REST API project developed using Python and FastAPI to collect, manage and provide job listing information.

## Technologies Used
- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Docker
- Redis
- Celery
- Swagger UI

## Features
- Collect job information from external sources.
- Store job information in a database.
- Search jobs by title and location.
- Provide REST API endpoints.
- API authentication.
- Rate limiting.
- Automatic data refresh.

## API Documentation
Swagger UI is available at:

http://localhost:8000/docs

## How to Run
1. Clone the repository.
2. Install dependencies.
3. Configure environment variables.
4. Start the application.
